Explorer Analanjirofo

Site web de voyage et découverte de la région d'Analanjirofo à Madagascar - Guide touristique complet avec destinations, culture, gastronomie et conseils pratiques

Voir le projet en ligne
Page d'accueil - Explorer Analanjirofo
HTML5 / CSS3 / JavaScript / Responsive
Description complète du projet

Explorer Analanjirofo est un site web de voyage complet dédié à la découverte de la région d'Analanjirofo, située sur la côte nord-est de Madagascar. Ce projet a été développé pour promouvoir le tourisme durable et authentique dans cette région riche en biodiversité et en traditions culturelles.

Fonctionnalités principales
  • Site responsive multi-pages (7 pages)
  • Filtrage dynamique des destinations par catégorie
  • Modale interactive pour les détails des destinations
  • Formulaire de contact avec validation JavaScript
  • Menu burger responsive pour mobile
  • Section newsletter interactive
  • Galerie d'images avec aperçu
  • Animations CSS au scroll

Projet DHTML - Application Web Interactive

Application web dynamique intégrant plusieurs fonctionnalités : résolution de systèmes d'équations (Cramer), redimensionnement d'images, publicité rotative et gestion de données avec DataTable

Voir le projet en ligne
Interface principale du projet
HTML5 / CSS3 / JavaScript / Bootstrap
Description complète du projet

Le projet DHTML est une application web complète développée dans le cadre de ma formation. Elle intègre plusieurs modules interactifs :

Module Cramer

Résolution de systèmes d'équations linéaires avec affichage détaillé des étapes et des résultats.

Module Image

Redimensionnement et manipulation d'images avec prévisualisation en temps réel.

Module Panneau Publicitaire

Système de publicité rotative avec changement automatique et manuel des bannières.

Module Datatable

Gestion avancée de données avec recherche, tri, pagination et graphiques statistiques.

  • Interface responsive avec Bootstrap 5
  • Navigation dynamique sans rechargement de page
  • Graphiques interactifs avec Chart.js
  • Animation et effets visuels avec jQuery UI
  • Gestion des données avec DataTables
Technologies utilisées
HTML5 CSS3 JavaScript Bootstrap 5 Chart.js DataTables jQuery & jQuery UI
